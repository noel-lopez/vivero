# Vivero 🌱

Sistema personal para llevar ideas de contenido del impulso a la publicación, cerrando la "última milla" que deja los borradores muertos.

App web local, single-user. Inspiración → Idea → Publicación, con generación de contenido vía Claude Code.

> 🚧 En diseño. Ver [`docs/mvp-overview.md`](docs/mvp-overview.md) para la visión y las decisiones del MVP.
